# Punane Pastakas — landing page candidates

Five landing page design proposals for RedPen / Punane Pastakas, presented as a
gallery for team review. Open the root page and click any card to view a design
full-screen. Each design also has a built-in `v1–v5` switcher to jump between
variants.

## Version mapping

| Version | Original file                   | Nickname     |
| ------- | ------------------------------- | ------------ |
| v1      | `Landing A - Marked Paper.html` | Marked Paper |
| v2      | `Landing B - Cinematic.html`    | Cinematic    |
| v3      | `Landing D - Tres Mares.html`   | Tres Mares   |
| v4      | `Landing E - Kontrolltöö.html`  | Kontrolltöö  |
| v5      | `Landing F - Codex.html`        | Codex        |

Note: the original lettering skipped `C`, so letters and version numbers are
offset from `v3` onward.

## Structure

- `index.html` — gallery / chooser (neutral styling on purpose)
- `v1/`…`v5/` — one design per folder, each as `index.html`
- `shared/` — CSS and JS used by all designs
- `assets/` — images used by some designs

Feedback is collected informally — open the link, pick a favourite, and tell
Kris. There is intentionally no voting mechanism.
